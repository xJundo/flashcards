# Icon library

Ready-to-paste inline SVGs for the `.icon-badge` in [template.html](./template.html)
— sourced from Lucide (the same icon set the app's own UI uses, ISC-licensed),
not emoji. Each is already sized/styled to drop straight into a badge:
`stroke="currentColor"` so it inherits the badge's `color`, no `width`/`height`
attributes (the `.icon-badge svg` CSS rule sizes it).

Use one only where a word names a concrete, illustratable thing — a person,
place, object, food, animal, weather, time-of-day. Don't force one onto
grammar particles, endings, or abstract words; leave those with no `.icon-badge`
at all (the layout copes fine with a row that has none).

## Anything not on this list

Don't invent an SVG path by hand. `lucide-react` is already installed at
`web/node_modules/lucide-react/dist/esm/icons/` — one small `.mjs` file per
icon, each just a `path`/`circle`/`rect` array. Find the closest-matching
name (`ls … | grep -i <keyword>`), open the file, and wrap its `__iconNode`
entries the same way the snippets above do:

```html
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
  <!-- one tag per iconNode entry, e.g. ["path", {d: "..."}] -> <path d="..."/> -->
</svg>
```

Keep every icon at this exact same `viewBox`/stroke setup — that's what makes
them read as one family instead of a grab-bag of styles.
